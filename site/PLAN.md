# Interactive plan

Working mockup: `index.html` + `data.js` (generated by `gen_data.py`).
Serve any static server; no build step, no dependencies. Hand-rolled SVG in
the style of the IARIW seed charts, with the dataviz-skill reference
palette (slots 1–3 validated light + dark; swap to `@policyengine/ui-kit`
tokens if the repo lands under PolicyEngine).

## Current state

Three views on the validated seed series (US SPF, real GDP growth, Q1
rounds): decomposition (total / average individual / disagreement),
consensus fan (next-year vs 10-year median + IQR), calibration (consensus
± total SD vs realizations, misses ringed and year-labeled). Crosshair
tooltips, data table per view, light/dark from one token block.

## Once outputs/measures.csv lands (sol pipeline)

- `gen_data.py` switches source to `outputs/` and emits the full matrix;
  the survey / variable / horizon selects become live (options read from
  the data manifest, disabled placeholders removed).
- Measure toggle on the decomposition view: SD-based vs pooled-IQR (the
  bin-robust companion), plus between-share strip.
- Two added views:
  - **Term structure** — stated uncertainty by horizon (US 0–3y, ECB
    1y/2y/longer-term), one line per survey-variable, the fixed-event
    within-year shrinkage as small multiples.
  - **Elicitation gap** — the one original diagram: horizons with density
    elicitation (bars per survey) against the published AI growth-effect
    range at 10y (from verified LITREVIEW citations only).
- Quarterly rounds: a Q1-only toggle vs all-rounds (fixed-event caveat in
  the note line).

## Publication

the manuscript; the interactive is the site's front page). Deployment
